# Тихое озеро

Бета сайта подготовки: первый экран с озером и отдельная страница заданий. HTML, CSS и обычный JavaScript, без установки пакетов и без внешних CDN.

## Запуск

```powershell
node server.mjs
```

Открыть http://127.0.0.1:4173. При необходимости другой порт задаётся переменной `PORT`.
Также можно открыть `index.html` напрямую в браузере.

## Анимация

Длительность заставки — 6,2 секунды. Сначала видна только капля на светлом фоне. Капля падает в озеро, появляются всплеск и круги, затем лес, пирс с рыбаком и кнопка слева. После заставки остаётся очень слабая рябь.

- Escape пропускает заставку; R запускает её заново, когда не открыт вариант.
- Системная настройка уменьшения движения сразу показывает финальную сцену.
- В неактивной вкладке анимация приостанавливается.
- При отсутствии WebGL для капли используется Canvas.
- На узких мобильных экранах сцена находится над кнопкой.

## Как сохранён референс

`assets/lake-reference.png` — выбранное пользователем изображение. Окружение — анимированные слои этого изображения (2.5D), а не процедурные 3D-модели. Капля — объёмная поверхность с вычисляемыми нормалями, отражением и преломлением, отрисованная WebGL. Всплеск и рябь — Canvas.

В конце слои сводятся к исходному изображению, чтобы сохранить точные цвета, берега, деревья и положение рыбака. Изображение масштабируется пропорционально под окно. Старое изображение кнопки закрыто фоном только в области кнопки; поверх находится независимая HTML-кнопка со стрелкой в круге. Это не полностью геометрическая 3D-сцена; свободного движения камеры вокруг леса и озера нет.

`?frame=0.8`, `?frame=2.1`, `?frame=3.8`, `?frame=6.2` позволяют открыть остановленные кадры для визуальной проверки. Удалить параметр, чтобы смотреть полную анимацию.

## Кнопка

Открывает `tasks.html`. При первом посещении собирается вариант, при следующих — продолжается сохранённый. На главной надпись кнопки автоматически меняется на «Продолжить вариант» или «Открыть вариант». На странице заданий есть отдельная кнопка «Новый вариант».

## Страница заданий

Панель номеров, одно задание на карточке, варианты ответа, прогресс, переходы и пропуск. Выбранный вариант, текущая позиция, ответы и факт завершения сохраняются в localStorage. Повторное открытие не запускает перемешивание. Перед заменой варианта с ответами появляется подтверждение.

После завершения показываются количество правильных, ошибочных и пропущенных ответов и разбор по номерам. Баллы по официальной системе олимпиады пока не начисляются.

На обеих страницах отключено выделение текста через общий файл стилей content-protection.css. Шапка страницы заданий содержит только ссылку на главную, без логотипа и метки «Бета».

В базе 480 заданий для 3–4 классов: 80 оригинальных из четырёх загруженных вариантов за 2023–2026 годы и 400 авторских — 20 дополнительных вариантов по 20 заданий. Удалённые материалы для 5–6 классов не используются. Вариант собирается из всей базы без дополнительных переключателей: для каждого из 20 номеров есть 24 задачи (4 оригинальных и 20 авторских). Ответы внутри задания не перемешиваются, чтобы буквенные обозначения совпадали с рисунками.

Оригиналы показаны фрагментами PDF с сохранёнными рисунками и графическими ответами; изображение можно открыть крупнее. Для поиска и доступности также сохранены текстовые условия. Ответы сверены с официальными ключами из https://mathkang.ru/rar. Авторские задания обозначены отдельно и снабжены объяснениями, которые появляются после завершения. Их расчёты проверяются независимыми решателями; педагогическая оценка сложности остаётся отдельным этапом.

Веса номеров сохранены в базе: 1–8 — по 3 балла, 9–16 — по 4, 17–20 — по 5. Интерфейс показывает количество верных ответов; официальная система стартовых баллов и штрафов не применяется.

### Файлы базы и пересборка

- `data/originals.json` — 80 оригинальных задач с источниками и ключами.
- `data/generated.json` — 400 авторских задач, объяснения и параметры независимой проверки.
- `data/author-sets.json` — состав каждого из 20 авторских вариантов.
- `data/catalog.json` — каталог всех 24 исходных наборов и сводка по номерам.
- `data/source-*.json`, `data/source-keys/` — контрольные суммы исходников и официальные ключи.
- `assets/tasks/originals/`, `assets/tasks/author/` — изображения условий и SVG-схемы.
- `task-bank.js` — готовая статическая база для браузера, сервер не требуется.

Авторские варианты воспроизводятся командой `node scripts/generate-author-variants.mjs`, затем база собирается командой `node scripts/build-bank.mjs`. Для повторного импорта оригиналов нужны исходные PDF и отрисованные развороты в `tmp/sources/render`; координаты и текст содержатся в `scripts/import-originals.py`. Для обычного запуска сайта Python, исходные PDF и папка `tmp` не нужны.

## Как добавить настоящие задания

База находится в `task-bank.js`:

```js
globalThis.KANGAROO_BANK = {
  id: 'kangaroo-school',
  version: 1,
  title: 'Название набора или класс',
  demo: false,
  pools: [
    { number: 1, tasks: [
      {
        id: '2025-task-1', number: 1, topic: 'Логика',
        text: 'Условие задания',
        options: ['Первый ответ', 'Второй ответ', 'Третий ответ', 'Четвёртый ответ', 'Пятый ответ'],
        correct: 2,
        image: { src: 'assets/tasks/example.svg', alt: 'Описание рисунка' },
        explanation: 'Необязательное объяснение решения'
      }
    ] }
    // Далее наборы number: 2, number: 3 и т. д. без пропусков.
  ]
};
```

`id` задачи должен быть уникальным во всей базе. `correct` — индекс правильного ответа с нуля. `image`, `explanation` и `topic` необязательны; если правильные ответы отсутствуют, страница сохраняет ответы без автоматической оценки. Условия и варианты — обычный текст, переносы строк в условии поддерживаются. Имена картинок задаются относительно корня сайта, например `assets/tasks/task-01.png`.

Задачи первого номера добавляются только в `number: 1`, второго — только в `number: 2`. Генератор берёт одну задачу из каждого соответствующего набора; порядок вариантов ответа не меняется. Несоответствие номера или отсутствие набора вызывает явную ошибку, а не сдвиг остальных задач.

При изменении содержимого существующей базы увеличивать `version`, чтобы старый сохранённый вариант не смешивался с новыми заданиями.

## Проверки

```powershell
node --test tests/variant-engine.test.cjs tests/content.test.mjs
```

36 проверок охватывают соответствие номеров, восстановление варианта, недопустимые сохранённые ответы, подсчёт результата, отсутствие набора и работу без доступного localStorage. Для всех 400 авторских задач независимые решатели проверяют результат и наличие единственного правильного варианта ответа. Для оригиналов проверяются состав, соответствие сверенным ключам, контрольные суммы PDF и наличие всех изображений.

## GitHub Pages

Сайт статический, сборка и серверная база не нужны. Для размещения нужны `index.html`, `tasks.html`, `styles.css`, `tasks.css`, `content-protection.css`, JavaScript-файлы приложения и каталог `assets`. Все ссылки приложения относительные, поэтому поддерживается размещение в подпапке репозитория. Файл `.nojekyll` отключает обработку Jekyll. `server.mjs` используется только для локального просмотра; в опубликованном сайте он не запускается.

Репозиторий: https://github.com/nechyrkk/quiet-lake-practice. Адрес Pages: https://nechyrkk.github.io/quiet-lake-practice/. Источник публикации — ветка `main`, корневая папка `/`. Последующие обновления отправляются командой `git push`, после чего GitHub Pages автоматически публикует изменения.

Предыдущая версия страницы сохранена локально в `index.previous.html`. Старые макеты, скриншоты, вспомогательные шрифты и папка `tmp` исключены из Git.
